# Academic Papers Workspace

Focused workspace for summarizing a small set of important papers for your literature review on teacher professional knowledge, teaching practice, and student achievement (including mathematics education and LMIC contexts).

## Folder themes

| Folder | Focus |
|--------|--------|
| `01_teacher-knowledge/` | Teacher professional knowledge |
| `02_teaching-practice/` | Classroom / instructional practice |
| `03_student-achievement/` | Student learning and achievement |
| `04_teacher-knowledge-to-practice/` | Knowledge → practice |
| `05_practice-to-achievement/` | Practice → achievement |
| `06_teacher-knowledge-to-achievement/` | Knowledge → achievement |

Place each paper’s Markdown summary in the theme folder that best matches its main contribution (one summary file per paper). PDFs may be stored alongside summaries locally; they are not tracked by Git (see repository `.gitignore`).

## Workflow

1. Identify a potentially important paper.
2. Decide whether it is **Core**, **Supporting**, or **Optional**.
3. Read the paper.
4. Create one Markdown summary using `paper_summary_template.md`.
5. Record only findings actually supported by the paper.
6. Add the paper to `../literature-review/key_papers.md`.
7. Periodically synthesize findings in `../literature-review/literature_synthesis.md`.
8. Use the synthesis—not isolated paper summaries—to draft `../literature-review/literature_review_outline.md` and eventually the manuscript.

## Important principle

> Do not cite a paper in the manuscript based only on an AI-generated summary. Verify the relevant claim against the original paper before citation.
